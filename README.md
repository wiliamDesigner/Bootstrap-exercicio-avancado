# Projeto Bootstrap - Loja de Armas

Este projeto e uma pagina web estatica criada como exercicio avancado de Bootstrap. A pagina simula uma loja de armas, com menu de navegacao, carrossel de imagens, secoes informativas, lista de produtos por categoria e formulario de contato.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5.3.3
- Bootstrap Icons
- Google Fonts

## Funcionalidades

- Cabecalho fixo com menu responsivo
- Carrossel de imagens com controles e indicadores
- Secao sobre armas e documentacao
- Secao informativa sobre seguranca
- Area de produtos com abas por categoria:
  - Armas brancas
  - Pistolas
  - Metralhadoras
  - Fuzil
- Formulario de contato
- Links visuais para redes sociais
- Layout responsivo usando o grid do Bootstrap

## Como executar

1. Baixe ou clone este repositorio.
2. Abra a pasta do projeto.
3. Clique duas vezes no arquivo `index.html`.

Tambem e possivel abrir o projeto com a extensao Live Server no Visual Studio Code.

## Arquivos principais

- `index.html`: contem a estrutura da pagina, componentes Bootstrap, secoes, produtos e formulario.
- `style.css`: contem as personalizacoes de cores, fontes, botoes, navegacao e links sociais.
- `img/`: contem as imagens usadas no carrossel e nas secoes do site.

## Observacoes

O projeto utiliza textos de exemplo em algumas secoes. Para transformar em um site final, e recomendado substituir os textos, revisar os nomes dos produtos, ajustar o titulo da pagina e corrigir os links de redes sociais e informacoes de contato.
